# Evidence that holds up

1. **Timestamp everything.** File names start with `YYYY-MM-DD`. Archive ads via web.archive.org "Save Page Now".
2. **Wired only.** Speed tests from an Ethernet-connected machine behind the modem, other heavy traffic paused.
3. **Raw + summary.** Keep the raw CSV from `tools/speedlog.sh` untouched; make graphs from copies.
4. **Two meters.** My Telenet screenshot + your own router counter for the same day.
5. **Every contact in `evidence-log.csv`.** Ticket number or it didn't happen. Prefer written channels over phone.
6. **Keep the contract version** that was valid on the day of the throttling (PDF + download date).
7. **Facts, no adjectives.** Regulators and the Ombudsdienst respond to numbers and dates.

Suggested folders: `ads/`, `contract/`, `usage/`, `speed/`, `correspondence/`, `screenshots/`.
